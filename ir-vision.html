Hardware interface

Browser serial requires desktop Chrome or Edge over HTTPS and a compatible serial device.

Connect VCC → 5V, GND → GND, OUT → D2. Upload the included Arduino UNO sketch ↗, then connect from desktop Chrome/Edge over HTTPS. The OUT signal is usually active LOW. This module cannot determine object shape, exact distance, temperature, or capture a real night-vision photo. The second spectrum is simulated and labelled.
