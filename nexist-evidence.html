NEXIST Evidence Lifecycle.

An evidence-aware extension of the NEXIST experimental model. Requirements are evaluated against explicitly selected records. The prototype records which evidence supported a decision, propagates invalidation across dependencies, and requires a separate approval before realization.

This browser playground is a temporary client-side demonstration and stores its sample records only in this browser's local storage. It is not connected to the Python engine. The Python reference implementation is in the repository's nexist-core folder.
