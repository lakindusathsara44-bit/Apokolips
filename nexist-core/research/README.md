# NEXIST Research Notes

This folder contains the initial related-work assessment and the benchmark protocol.

- [Related-work review](RELATED_WORK.md) — established approaches that overlap with current NEXIST features and the boundary of defensible novelty claims.
- [Comparative evaluation protocol](BENCHMARK_PROTOCOL.md) — feature-parity workload, metrics, interpretation limits, and reproducibility.
- [Initial benchmark results](BENCHMARK_RESULTS.md) — measured CI results with environment and caveats.

The current conclusion is deliberately cautious: NEXIST is an experimental data-model/API prototype. The present implementation is not enough to support a claim that it is a new fundamental data structure.
