Healthdiuno.

A web-based hardware diagnostic platform for Arduino and ESP32 development boards.

Connect a supported development board to a computer over USB, open the diagnostic interface, and run guided tests to inspect board communication, pins, power rails, and supported hardware functions.

Diagnostic goals

Pin diagnostics

Digital input/output, analog input, PWM output, and pin response checks using safe test procedures.

Power monitoring

Inspect measurable supply rails such as 5V, 3.3V, and input voltage where the board and test setup expose them.

Chip & interface checks

Check MCU communication, USB serial, UART, I²C, SPI, reset response, and other supported interfaces.

Visual health report

Show test results, pin maps, warnings, failed checks, and a downloadable diagnostic report.

Planned board support

Arduino UNOArduino MegaArduino NanoArduino LeonardoArduino MicroESP32ESP32-S2ESP32-S3ESP32-C3More board profiles
Diagnostic accuracy: Healthdiuno will report only what can be measured or verified by firmware and the connected test hardware. A USB connection alone cannot prove that every pin, chip, transistor, memory cell, oscillator, or internal circuit is healthy. Some tests will require loopback wiring or an external diagnostic fixture. Untestable components will be clearly marked as “Not tested” rather than incorrectly reported as healthy.

Planned workflow

  1. Connect a supported board using USB.
  2. Select or detect the board profile.
  3. Install or upload the matching diagnostic firmware when required.
  4. Run safe automatic checks and optional guided hardware tests.
  5. Review the board health map and export the report.
