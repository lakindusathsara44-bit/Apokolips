01 / Import SCI firmware

In the IDE, open File → Import Sketch, then select the downloaded sci_max4466_uno.ino file. The editor will create a sketch you can modify and save in this browser.

02 / Compile and upload

Select Arduino UNO, press Verify to compile, then connect the USB board and press Upload. The IDE checks the firmware before writing and verifies the uploaded flash where supported.

03 / Serial verification

Open Serial Monitor at 115200 baud. The SCI firmware should report SCI,<ADC> and STATE,0 or STATE,1. Only one browser tab/app can own the board's serial port at a time.

Browser and hardware requirements: Editing and compiling work in modern browsers. USB upload and Serial Monitor require desktop Chrome, Edge or Opera over HTTPS, a USB data cable, and permission to access the Arduino serial port. Android mobile browsers generally cannot use Web Serial. Close the Hardware Monitor serial connection and Arduino IDE Serial Monitor before connecting here.
