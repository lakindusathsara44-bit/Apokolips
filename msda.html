PROJECT 010 / MEASUREMENT RESEARCH

Multi-Scale Distance Analyzer.

A modular measurement platform. Phase 1 connects an Arduino UNO to a digital IR obstacle sensor and verifies live detection signals. Short-range and long-range distance measurement modules will be added only when compatible ranging sensors are available.

Connection checklist

  1. Use a USB data cable and connect the UNO.
  2. Upload the MSDA Phase 1 sketch.
  3. Close Arduino IDE Serial Monitor.
  4. Open this page in desktop Chrome or Edge over HTTPS.
  5. Press CONNECT ARDUINO and select the board's serial port.
Web Serial may not work in Android browsers or an in-app browser. If the Connect button is unavailable, use a supported desktop browser.
