EXPERIMENTAL INSTRUMENTATION / PHASE 01

Multi-Scale Distance Analyzer.

A modular measurement platform. Phase 1 uses the available 3-pin digital IR module to study object detection, signal transitions, timing, stability and repeatability. Distance readings remain disabled until a ranging sensor is connected.

HARDWARE NOT CONNECTED
Measurement integrity: This IR obstacle module has a binary digital output. It detects a reflected-IR threshold; it does not report millimetres. The dashboard will never invent a distance value. Surface colour, angle, ambient light and the onboard potentiometer can change its response.

Manual detection-boundary experiment

Move an object to a measured position using a ruler, then record whether the sensor detects it. Repeat at several positions and approach directions. The distance is manually supplied by you; the digital sensor does not measure it.

What this sensor can and cannot do

  • Can detect reflected IR crossing its comparator threshold.
  • Can report raw HIGH/LOW states and transition timing.
  • Can support repeatability experiments with manually measured distances.
  • Cannot directly output mm, cm, object shape, thermal data or an image.
  • For real short-range distance: add a ToF module such as VL53L0X / VL53L1X.
  • For longer range: add a suitable LiDAR or laser rangefinder selected for the target distance.
