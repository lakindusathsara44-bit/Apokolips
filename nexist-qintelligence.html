NEXIST Q-Intelligence.

A research prototype whose primary AI scoring model is a trainable variational Quantum Neural Network (QNN). It encodes numerical candidate features into qubits, applies trainable quantum gates and entanglement, measures Pauli-Z expectations, and learns from human-labelled examples. The QNN evaluates candidate suitability; NEXIST checks evidence and QAOA explores feasible portfolios.

02 / Quantum Neural AI engine

This is the primary learning and scoring model. Label at least four candidates (including both suitable and unsuitable examples), then train the four-qubit variational circuit. The model converts Pauli-Z expectation values into a suitability score. Those scores influence the QAOA objective; they never replace evidence requirements or human review.

Circuit: feature rotations RY(πxᵢ), RZ(π(xᵢ−0.5)) → two trainable RY/RZ layers → entangling CNOT gates → Pauli-Z measurements.

Readout: p(suitable|x) = σ(b + Σᵢ wᵢ⟨Zᵢ⟩). Training uses the parameter-shift rule: ∂⟨Z⟩/∂θ = [⟨Z⟩(θ+π/2) − ⟨Z⟩(θ−π/2)] / 2.

Four-qubit local state-vector simulation (16 complex amplitudes). The readout and optimizer are classical; the model is a hybrid variational quantum classifier, not a general-purpose text generator or physical quantum computer.

03 / QAOA portfolio selection engine

The QAOA-style portfolio solver uses the QNN-adjusted candidate utility in its phase operator, then applies an RX mixer and samples a probability distribution. With no trained QNN, the neutral suitability value 0.5 leaves the original benefit unchanged. A small exhaustive classical search is reported as a correctness reference.

05 / Research limits

This project is a hybrid prototype, not a verified new data structure or a quantum-advantage demonstration.

Learning boundary

The QNN is a supervised suitability classifier, not a general-purpose text generator. It learns only from the candidate labels and numerical features supplied in this demo.

Quantum boundary

The QNN and QAOA execute as small state-vector simulations on a classical machine. No physical QPU or quantum advantage is claimed.

Evidence boundary

Source labels and timestamps do not authenticate documents or identities. Real deployment needs access control, signed provenance, and durable audit storage.

Decision boundary

Optimization only returns a recommendation. It never calls realization, spends money, launches infrastructure, or executes real-world actions.

This demonstration stores sample records in this browser's local storage. It is separate from the persistent Python core engine.
