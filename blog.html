HOW THIS BLOG WILL BE UPDATED

Add photos & videos through GitHub

  1. Open this repository on GitHub and enter the trip-media folder.
  2. Choose Add file → Upload files and upload your trip photos or MP4 videos.
  3. After uploading, add the media to this page using an image or video card (the examples are included in the page source).
  4. Commit the changes to publish them with the website.

Tip: Keep videos reasonably compressed. GitHub is suitable for small website assets, but it is not a dedicated video-streaming service.
