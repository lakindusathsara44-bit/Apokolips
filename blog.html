Adding your future trip media
  1. Open the Apokolips GitHub repository and upload files into trip-media/.
  2. Use JPG, PNG or WebP for photos, and MP4 for videos.
  3. Open blog.html and add each file to the tripMedia list in the script, with its caption and date.
  4. Commit the changes to GitHub. GitHub Pages will publish the updated blog.

Tip: For large videos, use YouTube (Unlisted) or a video-hosting service and embed the video instead of storing huge files in Git.
