Live microphone signal

Filtered analog ADC signalArduino ADC threshold
STATE,0 — NormalSTATE,1 — High noise

This setting controls the Arduino binary threshold in Website mode. In Fixed mode, the firmware uses FIXED_THRESHOLD from the sketch.

The Arduino sends SCI,<ADC> for the filtered analog reading and STATE,0/1 for its threshold decision. Website mode sends MODE,WEB and TH,<value>; Fixed mode sends MODE,FIXED. The browser timer keeps the 1.5-second silence grace period. ADC readings are relative counts, not calibrated dB/SPL.
